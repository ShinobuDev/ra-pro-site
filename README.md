# RA-PRO — site et téléchargements

Page de vente de RA-PRO, logiciel de rapprochement bancaire pour Windows :
**https://shinobudev.github.io/ra-pro-site/**

- `index.html` : la page (un seul fichier, images incluses). Les liens de paiement, de
  téléchargement et les pages légales se règlent dans le bloc `CONFIG` en bas du fichier.
- Les installateurs sont publiés dans les [versions](https://github.com/ShinobuDev/ra-pro-site/releases)
  de ce dépôt. Le lien `releases/latest/download/RA-PRO-Setup.exe` pointe toujours vers la
  dernière version.

Le code source de RA-PRO n'est pas public.
